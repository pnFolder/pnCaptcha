# v1.2.3 — Полная очистка временных ресурсов

Релиз закрывает оставшиеся пути накопления временных объектов при disconnect, timeout, delayed actions и остановке Velocity.

## Исправлено
- Просроченные записи verification-кэша автоматически очищаются каждую минуту.
- Отложенные Actions отменяются при завершении сессии игрока и при shutdown.
- Отложенные задачи освобождения Limbo-миров отслеживаются и отменяются при shutdown.
- Версия плагина и версия публикуемого JAR синхронизированы с релизом.

## Совместимость
- Velocity 3.5.x.
- Java 21.
- LimboAPI 1.1.26 или новее.
