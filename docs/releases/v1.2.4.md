# v1.2.4 — Перевод на pnLibrary

Плагин подключён к pnLibrary 0.0.1-dev.6 и использует её возможности вместо собственных.

## Изменено
- Bootstrap: при отсутствии pnLibrary плагин устанавливает её сам.
- Диагностика, обновления и метрики (bStats, fast-stats) идут через pnLibrary.
- Единый логгер модуля: исключения попадают в журнал целиком.
- Задачи, команды и кулдауны работают на планировщике и командах pnLibrary.
- В репозиторий добавлен Gradle wrapper.

## Совместимость
- Velocity 3.5.x.
- Java 21.
- LimboAPI 1.1.26 или новее.
