Новая визуальная система полностью перерабатывает внешний вид 3D CAPTCHA: символы стали крупнее и детальнее, получили контролируемые пустоты, смешанные материалы, цветовые кластеры и отдельный читаемый контур.

## Добавлено
- Добавлен новый встроенный декоративный шрифт `ornate-9x12` для крупных и детализированных 3D-символов.
- Добавлен режим заполнения `porous`, который создаёт контролируемые пустоты внутри букв и цифр.
- Добавлена настройка `geometry.fill.density` для управления плотностью символов.
- Добавлена защита связности glyph при прореживании, чтобы символ не распадался на отдельные случайные части.
- Добавлена защита концевых элементов штрихов через `protect-endpoints`.
- Добавлена настройка `outline-preserve-percent`, позволяющая сильнее сохранять внешний силуэт символа.
- Добавлена настройка `min-retained-pixels`, защищающая небольшие символы и пользовательские шрифты от чрезмерного прореживания.
- Добавлен новый режим палитры `clustered`.
- Добавлена настройка минимального и максимального размера цветовых кластеров.
- Добавлена отдельная палитра `outline` для внешнего контура символов.
- Добавлена отдельная вероятность применения outline-материалов.
- Добавлена возможность смешивать stained glass, terracotta, copper, deepslate, blackstone и другие Minecraft-материалы внутри одной CAPTCHA.
- Добавлен новый мозаичный стандартный визуальный стиль.
- Добавлены готовые конфигурационные примеры разных визуальных направлений.
- Добавлен полноценный пример собственного bitmap-шрифта.
- Добавлены расширенные примеры BossBar Actions.
- Добавлены расширенные примеры обычных Actions.
- Добавлен готовый пример маршрутизации для нескольких lobby-серверов.

## Улучшено
- Увеличена стандартная дистанция до CAPTCHA, чтобы более крупная конструкция полностью помещалась в поле зрения игрока.
- Переработан стандартный угол всей сцены для более фронтального отображения символов.
- Увеличена стандартная 3D-глубина символов без чрезмерного увеличения их визуальной массы.
- Уменьшен случайный positional jitter отдельных букв.
- Основная сложность CAPTCHA теперь может создаваться формой символов, пустотами, материалами и цветовой структурой вместо сильного хаотичного смещения букв.
- Улучшена читаемость porous-символов благодаря независимому тёмному контуру.
- Переработана стандартная передняя палитра CAPTCHA.
- Боковые и задние поверхности получили более тёмные материалы для лучшего восприятия настоящей 3D-глубины.
- Переработаны визуальные помехи вокруг CAPTCHA.
- Стандартный noise стал менее плотным и меньше перекрывает основной код.
- Сохранена возможность полностью вернуться к прежнему плотному стилю `classic-5x7` только через конфигурацию.
- Существенно расширена документация `config.yml`.
- Для настроек теперь указываются назначение, допустимые значения, специальные значения и практические примеры.
- Расширено описание Routing, Limbo, Recovery, Randomness, Palette, Noise и Camera.
- Подробно расписана система Actions.
- Подробно расписаны все BossBar operations и связанные параметры.
- Добавлены рекомендации по настройке `density`, расстояния, размера цветовых кластеров и outline.
- README дополнен описанием новой визуальной системы и готовых конфигурационных примеров.

## Примеры настройки

### Мозаичный стиль

Крупная CAPTCHA на большей дистанции с контролируемыми пустотами, смешанными материалами и тёмным контуром.

```yaml
scene:
  distance-blocks: 42.0
  center-height-blocks: 7.0
  rotation:
    yaw-degrees: 8.0
    pitch-degrees: 0.0
    roll-degrees: 0.0

font:
  preset: "ornate-9x12"

geometry:
  pixel-width: 1
  pixel-height: 1
  depth-blocks: 4
  fill:
    mode: "porous"
    density: 0.78
    preserve-connectivity: true
    protect-endpoints: true
    outline-preserve-percent: 78.0
    min-retained-pixels: 14

palette:
  mode: "clustered"
  cluster-size-min: 2
  cluster-size-max: 5
  outline:
    enabled: true
    chance-percent: 86.0
```

### Более плотная мозаика

Для серверов, где хочется сохранить новый материал-стиль, но сделать буквы заметно легче читаемыми.

```yaml
font:
  preset: "ornate-9x12"

geometry:
  fill:
    mode: "porous"
    density: 0.92
    preserve-connectivity: true
    protect-endpoints: true
    outline-preserve-percent: 92.0

palette:
  mode: "clustered"
  cluster-size-min: 2
  cluster-size-max: 4
  outline:
    enabled: true
    chance-percent: 95.0
```

### Агрессивная porous CAPTCHA

Больше пустого пространства внутри символов и более выраженная мозаичная структура.

```yaml
geometry:
  fill:
    mode: "porous"
    density: 0.58
    preserve-connectivity: true
    protect-endpoints: true
    outline-preserve-percent: 85.0
    min-retained-pixels: 14

palette:
  mode: "clustered"
  cluster-size-min: 1
  cluster-size-max: 3
  outline:
    enabled: true
    chance-percent: 95.0
```

### BossBar как таймер CAPTCHA

```yaml
actions:
  triggers:
    challenge-start:
      - type: "bossbar"
        bossbar-id: "captcha-timer"
        bossbar-operation: "animate"
        text: "<gradient:#54F4D1:#4D9CFF><bold>pnCaptcha</bold></gradient> <dark_gray>• <white>{bossbar_seconds}s</white>"
        bossbar-color: "blue"
        bossbar-overlay: "progress"
        bossbar-start-progress: 1.0
        bossbar-end-progress: 0.0
        bossbar-duration-ms: 0
        bossbar-update-interval-ms: 100
```

### Штраф BossBar за неправильный ответ

```yaml
actions:
  triggers:
    wrong-answer:
      - type: "bossbar"
        bossbar-id: "captcha-timer"
        bossbar-operation: "add-progress"
        bossbar-progress-delta: -0.12
        bossbar-color: "red"
        text: "<red><bold>Неверно</bold></red> <dark_gray>• <white>{remaining}</white> <gray>попыток</gray>"
```

### Несколько lobby-серверов

```yaml

  servers:

      priority: 10
      weight: 5
      max-players: 150
      reserve-slots: 5

    - name: "lobby-2"
      enabled: true
      priority: 10
      weight: 5
      max-players: 150
      reserve-slots: 5

    - name: "fallback"
      enabled: true
      priority: 100
      weight: 1
      max-players: 80
      reserve-slots: 2
```
