# v1.2.2 — Защита от исчерпания direct memory

Релиз ограничивает одновременное создание CAPTCHA Limbo-миров и снижает пиковое потребление off-heap памяти Netty при всплеске подключений.

## Исправлено
- Исправлено переполнение Netty direct buffer memory при массовом создании CAPTCHA Limbo.
- Повторная проверка `security.max-active-captchas` выполняется непосредственно перед созданием мира и защищена от гонки между одновременными join-callback.
- При достижении безопасного предела игрок получает штатное событие `busy`, а не запускает ещё один тяжёлый Limbo.

## Улучшено
- Безопасный лимит активных CAPTCHA по умолчанию снижен со 128 до 16.
- Максимально допустимое значение `security.max-active-captchas` ограничено 64, чтобы настройка не могла отключить защиту от off-heap переполнения.
- Сохранён padding в 1 чанк вокруг сцены, чтобы повороты и границы CAPTCHA не обрезались; ограничение памяти достигается лимитом одновременных миров.
- Добавлен регрессионный тест на безопасные лимиты ресурсов.
- Просроченные записи verification-кэша теперь очищаются автоматически каждую минуту.
- Отложенные Actions и задачи освобождения Limbo отслеживаются, отменяются при disconnect и корректно закрываются при shutdown.

## Совместимость
- Velocity 3.5.x.
- Java 21.
- LimboAPI 1.1.26 или новее.
