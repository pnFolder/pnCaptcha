# v1.2.1 — Исправлена отправка статистики

Версия делает подключение pnCaptcha к bStats надёжным и показывает реальное состояние отправки статистики.

## Улучшено
- Состояние глобального bStats теперь проверяется через `plugins/bStats/config.txt` и явно отображается в журнале Velocity.
- В журнал добавлено пояснение о задержке первого отчёта и обновления публичной статистики.
- Сборка проверяет наличие relocated-классов bStats и отсутствие конфликтующих классов `org.bstats` в итоговом JAR.

## Исправлено
- Сообщение об успешном запуске метрик больше не выводится, когда глобальная отправка bStats отключена.
- Ошибка инициализации или остановки bStats больше не прерывает работу pnCaptcha.
- bStats запускается только после успешной инициализации основных сервисов плагина и корректно останавливается вместе с proxy.

## Совместимость
- Velocity 3.5.x.
- Java 21.
- LimboAPI 1.1.26 или новее.
